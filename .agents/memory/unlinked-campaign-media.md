---
name: Unlinked campaign media
description: Policy for participant uploads when a campaign has no catalogue game.
---

Campaigns without a linked catalogue game must still support creator media submissions. Allow participant-owned, game-unassigned uploads made after joining that campaign, while keeping the game-ID match for linked campaigns. Do not invent a catalogue game or show an unrestricted library picker to solve the missing link.

**Why:** Gamefolio-managed and sample campaigns can have only a game name and artwork; requiring a catalogue ID caused files to upload successfully but fail when attached to the campaign. Linking these campaigns to an unrelated public game would misattribute the content.

**How to apply:** Preserve the two-step upload and campaign confirmation flow for clips, reels, and screenshots. For unlinked campaigns, verify ownership, upload timing, and that the media was not used for another campaign; linked campaigns continue to validate against their catalogue game.
