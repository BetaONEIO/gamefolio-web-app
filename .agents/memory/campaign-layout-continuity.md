---
name: Campaign layout continuity
description: Active and reviewed campaign states should retain the available campaign's editorial layout.
---

Treat accepting a campaign as a change of state on the same recognizable page: keep the hero, game details, horizontal mission icons and right-hand rewards, then place compact creation controls within those mission columns. Under review, approved, and changes requested should keep that structure rather than switching to a dashboard or full-width objective cards.

**Why:** The creator chooses a campaign based on its advertisement; a different active layout breaks recognition and makes the work feel like an unrelated admin form. The user explicitly corrected a prior full-width objective-card redesign.

**How to apply:** Put preparation progress above the mission columns and submission action in a compact footer. Open larger editors in a focused dialog so columns stay compact. Show rewards as locked until owner approval; ready media alone never earns completion XP. On desktop adapt mission columns to the actual objective count, and stack them only on narrow screens.
