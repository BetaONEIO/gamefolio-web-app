---
name: Developer upload ownership
description: Product rule limiting Game Developer uploads to their catalogue-linked games.
---

Game Developers may upload clips, reels, and screenshots only for catalogue games explicitly linked through their Indie profiles. Do not reintroduce an "other games" publishing option or allow a client-side game selection to bypass this rule.

**Why:** Developers use this workflow to publish official game content rather than creator content for unrelated titles.

**How to apply:** Enforce ownership at the server-side upload boundary for every content type and keep the Developer Dashboard scoped to linked catalogue games.
