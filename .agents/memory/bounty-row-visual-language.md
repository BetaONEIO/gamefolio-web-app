---
name: Bounty row visual language
description: Visual rules for the My Campaigns mission rows in the Gamefolio Bounty Hub.
---

My Campaigns rows use a near-black neutral surface on #0F101B, real game artwork for visual variation, white/grey typography, and neon green as the only primary accent. Objective cards stay in one horizontal row; overflow scrolls horizontally instead of wrapping into a second row. Statuses are plain text with a dot or check instead of colored pills; progress uses a neutral track with neon-green completion; rewards and deadlines stay unboxed and restrained.

**Why:** Strong blue panels, rainbow status colors, repeated pills, and tinted containers made the campaign rows read as generic SaaS dashboard UI instead of Gamefolio.

**How to apply:** Build hierarchy with typography, spacing, alignment, artwork, subtle neutral dividers, and one accent color. Keep objective rails non-wrapping with readable minimum card widths and horizontal overflow on narrow layouts. Reserve the brightest neon treatment for the primary CTA and small progress/status accents.
